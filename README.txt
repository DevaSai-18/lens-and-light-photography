LENS & LIGHT — PHOTOGRAPHY WEBSITE
===================================

Files
-----
index.html  Main website structure and content
style.css   Responsive layout, colours, typography and styling
script.js   Mobile navigation, gallery filters and booking dashboard

How to run
----------
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html (or open it with Chrome).
4. Keep an internet connection available for Google Fonts and Unsplash photographs.

Booking feature
---------------
- Visitors can submit their name, email, service and booking date.
- JavaScript saves each booking in the browser's localStorage.
- The Booking Dashboard shows total bookings, unique dates, and bookings for a selected date.
- Booking records remain in that same browser until its site data is cleared.

IMPORTANT LIMITATION
--------------------
This project uses only HTML, CSS and JavaScript, as required by the class instructions.
localStorage is device/browser-specific. Bookings made on your laptop will NOT automatically
appear on your teacher's phone. To share bookings across devices, an online database or
backend would be required, which is outside the current "HTML, CSS, JavaScript only" scope.

Other features
--------------
- Responsive navigation
- Gallery filters: Nature, Wildlife, Wedding, Travel and Portrait
- Photography services and About section
- Contact details and social links
- Semantic HTML, CSS Flexbox, Grid, media queries and hover effects

Replace sample contact details with your team's approved details.
Photographs are loaded from Unsplash URLs, so internet access is needed for them.


Dashboard booking management
----------------------------
- Cancel: removes one selected booking after confirmation.
- Hide bookings / Show bookings: hides or reveals the table without deleting records.
- Clear all bookings: permanently removes all bookings stored in this browser after confirmation.
- Booking data uses browser localStorage and is not shared between devices.
